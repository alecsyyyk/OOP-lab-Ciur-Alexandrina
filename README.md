# OOP Lab 2 - Analytics Dashboard

## Project Overview

This project implements an Analytics Dashboard application in Java, following Object-Oriented Programming principles.

## Implementation Notes

**No changes have been made since Handout 1.**

This implementation has been guided solely based on the scheme provided in Handout 1. The design and structure follow the original specifications without modifications.

## Project Structure

The application consists of the following components:

- `MainApp.java` - Main entry point of the application
- `DashboardManager.java` - Manages dashboard operations
- `AnalyticsDashboard.java` - Core dashboard implementation
- `DataService.java` - Handles data operations
- `Exporter.java` - Export functionality
- `analytics_export.csv` - Sample export data
- `output.csv` - Generated output file
